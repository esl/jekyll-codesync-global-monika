Loïc Hoguin

A Tale of 2.0 Cowboys

Cowboy 2.0 is the new modern HTTP server for Erlang/OTP. It leads the way with its friendliness, reliability, performance and standards support. We will discuss the important changes in Cowboy, the tools that emerge around it and the plans for the future.

Talk objectives:

  • Get up to date with recent Cowboy developments, and learn new best practices that were identified while working on it.

Target audience:

  • Everyone
