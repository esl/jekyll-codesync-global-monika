Lessons Learnt Rewriting an Existing PubSub Erlang System

bet365 has been using Erlang/OTP for a few years now. The quality of the code base has improved as more experience is gained working with Erlang. This talk describes the experience gained while re-writing one of the first systems developed in Erlang. This talk will offer insights into the architecture of a busy message publishing system.
