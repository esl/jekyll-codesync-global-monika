MyETS - getting Millions of Config Records from MySQL to ETS

Overview of MyETS an new open source project that was created in AOL to tackle difficult task of keeping hundreds of machines up to date with millions of different configuration settings stored in MYSQL db that need to be delivered to all nodes in matter of seconds.

Talk objectives:

Introduce new open source project

Target audience:

- Engineers working with large scale systems.
