Max Lapshin
Author of erlyvideo
erlyvideo

From 2004 Max  spent a lot of time working on creating web sites. He has experience in integrating web-interface into large 2M+ LOC project on C++. Since 2009 he has been working with video streaming and has experience in ObjectiveC. Now for almost 2 years Max has been working with Erlang and is now the main author of erlyvideo and owner of this business.
Max Lapshin is Giving the Following Talks
Code generation to fight with complexity

Code generation to fight with complexity: Max Lapshin from Erlang Solutions on Vimeo.

Stock exchanges use complicated protocol FIX. How to simplify work with it and minimize "glue" code between parser and your business logic?

In this talk Max'll tell how automatic code generation can help to simplify connection to enterprise protocols.
