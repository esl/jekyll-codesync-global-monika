Know your VM inside out - instrument it using Exometer

Exometer is a open-source framework for instrumenting an Erlang systems. It is carefully designed to consume minimal resources while providing lots of choices for gathering data and exporting it to external monitoring systems. This talk will compare Exometer with other instrumentation solutions and highlight is flexibility for almost any use-case one can encounter.

Talk objectives:

Educate the audience about using Exometer for their monitoring needs

Target audience:

Erlang developers
