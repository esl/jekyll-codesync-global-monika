London 2009

Dominic Williams
Software developer - Erlang and Extreme Programming

Dominic has been developing software for 15 years, mostly in telecoms, railways signalling and oceanography. His principal areas of interest are eXtreme Programming, high-availability distributed systems and Erlang. He currently manages 32 developers writing mobile telephony server software, mostly in Erlang.

Dominic Williams is Giving the Following Talks
Erlang Test Idioms

Test-driven development has a profound impact on how we design and code. This technical talk presents various Erlang idioms that make code more testable and shows how test-driven development and Erlang are complementary.
