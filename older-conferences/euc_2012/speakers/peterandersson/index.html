Erlang User Conference 2012

Peter Andersson
Developer at Erlang/OTP with Common Test expertise
Ericsson AB

Peter Andersson is a software engineer who has worked with Erlang development and test in various Ericsson projects since 1997. In 2001 he joined the Erlang/OTP team and has for the past few years worked largely with development and maintenance of the Common Test and Test Server applications that are part of the OTP product. Peter also gives Erlang and Common Test courses on a regular basis.

Favourite quote: "I've had three Lattes and an Americano, I'm blazing!" - Vince Noir

twitter: @pekadan
Peter Andersson is Giving the Following Talks
Tutorial: Common Test - Getting Started and Moving On - Part 1

Peter will present the Common Test application by giving a general introduction to the tool, as well as explaining some interesting features in more detail.

Tutorial objectives: The tutorial should give the listener a general idea about the purpose and usefulness of Common Test, and a good enough basic understanding of the tool, to help them get started with it quickly in their projects.

Target audience: Anyone interested in learning about Common Test; a general purpose test tool, useful for testing systems on any level.
